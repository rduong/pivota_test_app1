/pivota_spec-new-project Todo List App with User Management - Project Specification
Core Value
A todo list web application with user access control, allowing teams or individuals to organize tasks with admin user management and invite system.

Project Overview
Project Name: Todo List App with User Management
Type: Single-page web application (HTML/CSS/JS)
Core Functionality: A todo list app where users can manage their tasks, with admin user management and invite system
Target Users: Teams or individuals who want to organize tasks with user access control
User Roles
Admin
Can create invite links with unique codes
Can view all users in the system
Has full access to all users' todo lists
User
Can add, update, delete their own todo items
Cannot access admin features
Access via invite code registration
Technical Stack
Frontend: Pure HTML/CSS/JavaScript (single-file SPA)
Data Storage: localStorage
Fonts: Google Fonts (Outfit)
No external frameworks required
