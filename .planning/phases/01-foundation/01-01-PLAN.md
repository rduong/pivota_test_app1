Create index.html as a single HTML5 document. The file is the entire app — HTML structure, embedded CSS, and embedded JS all in one file (TechArch: single-file architecture, no build step).

**HTML Head (exact structure required):**
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>TodoApp</title>
  <!-- Google Fonts: Outfit — verified CDN URL (weights 300-700, font-display: swap) -->
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link href="https://fonts.googleapis.com/css2?family=Outfit:wght@300;400;500;600;700&display=swap" rel="stylesheet">
  <style>
    /* CSS design system goes here — see Task 2 */
  </style>
</head>
<body>
  <div id="app">
    <!-- All views rendered here by Router -->
  </div>
  <script>
    // All JavaScript namespaces go here — populated in Plans 02 and 03
  </script>
</body>
</html>
```

**Important:** The `<div id="app">` is the ONLY persistent DOM element. All view HTML is injected via `element.innerHTML` by the Router. No view HTML should be hardcoded in the body.

The script block should contain only a comment stub for now — full JS is added in Plans 02 and 03.
