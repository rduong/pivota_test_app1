In `UI.bindEvents(view, context = {})`, make two changes:

**Change 1 — Replace the login form submit placeholder with the async handler.**
Find the existing placeholder:
```javascript
          // Login form submission — placeholder for Phase 2 (Auth)
          const loginForm = document.getElementById('login-form');
          if (loginForm) {
            loginForm.addEventListener('submit', (e) => {
              e.preventDefault();
              // Auth.login() wired in Phase 2
            });
          }
```
Replace with:
```javascript
          // Login form submission — async handler (FR-F1.1, FR-F1.2, FR-F1.5)
          const loginForm = document.getElementById('login-form');
          const loginBtn = document.getElementById('login-btn');
          if (loginForm) {
            loginForm.addEventListener('submit', async (e) => {
              e.preventDefault();

              // Clear previous error messages before re-validation
              document.getElementById('username-error').textContent = '';
              document.getElementById('password-error').textContent = '';

              const username = document.getElementById('username').value;
              const password = document.getElementById('password').value;

              try {
                // Disable button during async operation — prevents double-submit
                if (loginBtn) { loginBtn.disabled = true; loginBtn.textContent = 'Logging in…'; }

                const result = await Auth.login(username, password);

                if (!result.ok) {
                  if (result.error === 'EMPTY_FIELDS') {
                    // FR-F1.2 rule 1: field-specific required errors
                    if (!username.trim()) {
                      document.getElementById('username-error').textContent = 'Username is required.';
                    }
                    if (!password) {
                      document.getElementById('password-error').textContent = 'Password is required.';
                    }
                  } else {
                    // FR-F1.2 rules 2-3: generic message — do NOT reveal which field is wrong
                    document.getElementById('username-error').textContent = 'Invalid username or password.';
                  }
                  return;
                }

                // FR-F1.5: route by role — Router.navigate() handles role guards
                if (result.session.role === 'admin') {
                  Router.navigate('ADMIN_DASHBOARD');
                } else {
                  Router.navigate('USER_DASHBOARD');
                }
              } finally {
                // Always re-enable button — even if Auth.login() throws
                if (loginBtn) { loginBtn.disabled = false; loginBtn.textContent = 'Log In'; }
              }
            });
          }
```

**Critical notes:**
- The handler MUST be `async (e) => { ... }` — without `async`, `await Auth.login()` silently returns a Promise, `result.ok` is `undefined`, and login never works
- Use `try/finally` — the `finally` block ALWAYS re-enables the button regardless of success, failure, or exception
- Do NOT call `Router.navigate('LOGIN')` on error — that would re-render the form and clear fields. Update error spans in-place only
- Clear error messages at the TOP of the handler before calling Auth.login()

**Change 2 — Add logout binding after the REGISTER view block.**
After the closing `}` of the `if (view === 'REGISTER')` block and before the final `}` closing `bindEvents`, add:

```javascript
        // FR-F1.4: Logout binding for both authenticated views

          }
        }
```
