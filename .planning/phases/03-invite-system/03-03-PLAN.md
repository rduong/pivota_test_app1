17. Navigate to REGISTER view
18. Submit with empty username → error appears under Username field; other fields retain their values

21. Submit with invite code "BADCODE1" → "Invite code not found. Please check the code and try again."
22. Submit with mismatched passwords → "Passwords do not match." under Confirm Password field
23. Submit with password "short" → "Password must be at least 8 characters." under Password field

**Scenario 5 — Used code shows in admin list:**
24. Login as admin
