Insert a new `const Users = { ... }` namespace into index.html's `<script>` block, AFTER the `InviteCodes` namespace and BEFORE the `UI` namespace.

**TechArch — exact User shape (copy field names verbatim):**
```typescript
interface User {
  username: string;           // 3–30 chars, alphanumeric + underscore
  passwordHash: string;       // Client-side hash of password (SHA-256 hex)
  role: 'admin' | 'user';
  registeredAt: string;       // ISO 8601 timestamp
  inviteCode: string | null;  // Code used to register; null for seeded admin
}
```

Implement `Users.register(username, password, confirmPassword, inviteCode)` as an `async` function. It MUST enforce FRD §FR-F2.2 validation in EXACT ORDER — return on first failure:

```
Validation order (FR-F2.2):
1. All fields non-empty:        return { ok: false, field: 'username'|'password'|'confirmPassword'|'inviteCode', message: '...' }
2. Username format (3-30 chars, /^[a-zA-Z0-9_]{3,30}$/): field: 'username'
3. Username not already taken:  field: 'username', message: "This username is already taken. Please choose another."
4. Password ≥8 chars:           field: 'password', message: "Password must be at least 8 characters."
5. Passwords match:             field: 'confirmPassword', message: "Passwords do not match."
6. Invite code exists:          field: 'inviteCode', message: "Invite code not found. Please check the code and try again."
7. Invite code not used:        field: 'inviteCode', message: "This invite code has already been used."
```

On validation pass, perform registration:
```javascript
// a. Hash password — MUST use await (hashPassword is async)
const passwordHash = await hashPassword(password);
// b. Create User object — exact TechArch shape
const newUser = {
  username,
  passwordHash,
  role: 'user',
  registeredAt: new Date().toISOString(),
  inviteCode: inviteCode.trim()
};
// c. Append user to todoapp_users
const users = Storage.get(Config.KEYS.USERS, []);
users.push(newUser);
Storage.set(Config.KEYS.USERS, users);
// d. Mark invite code as used
InviteCodes.markUsed(inviteCode.trim(), username);
// e. Create session and persist to todoapp_session
const session = { username, role: 'user' };
Storage.set(Config.KEYS.SESSION, session);
// f. Return success
return { ok: true };
```

Return type: `{ ok: true }` on success, `{ ok: false, field: string, message: string }` on validation failure.

Also add `Users.find(username)` — returns user object by username or null. Used by Phase 5 Admin visibility.

**Implementation notes:**
- `username.trim()` and `inviteCode.trim()` before all comparisons and storage
- Check non-empty BEFORE format check — empty string would pass `length >= 3` test differently
- For empty field checks, test each field independently in order: username → password → confirmPassword → inviteCode
- `hashPassword` is defined in the same script block — `await hashPassword(password)` is correct
- `InviteCodes.find(inviteCode.trim())` returns null if not found, object if found
- `invite.usedBy !== null` means it's already used
  </action>
